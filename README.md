# 🍕 Pizza Sales Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing a pizza sales dataset using SQL to extract meaningful business insights. The analysis covers sales performance, customer preferences, and revenue trends.

---

## 🎯 Objectives
- Analyze overall sales performance  
- Identify top-selling pizzas and categories  
- Understand customer preferences  
- Examine order patterns over time  
- Generate insights for business decision-making  

---

## 🗂️ Dataset
Database: **pizzahut**

Tables used:
- orders  
- order_details  
- pizzas  
- pizza_types  

---

## 🛠️ Tools & Technologies
- SQL (MySQL)  
- MySQL Workbench  

---

## 🔍 Key Analysis Performed

### 🔹 Basic Analysis
- Total number of orders  
- Total revenue generated  
- Most common pizza size  
- Top 5 most ordered pizza types  

### 🔹 Intermediate Analysis
- Category-wise quantity of pizzas ordered  
- Distribution of orders by hour  
- Average pizzas ordered per day  

### 🔹 Advanced Analysis
- Percentage contribution of each category to total revenue  
- Cumulative revenue over time  
- Top 3 pizzas by revenue (overall and category-wise)  

---

## 📊 Key Insights
- Classic category generates the highest revenue (~26.9%)  
- Large (L) size pizzas are most preferred by customers  
- A small number of pizza types contribute significantly to total sales  
- Sales are evenly distributed across categories  
- Peak order times occur during afternoon and evening  
- Average daily orders (~138) indicate stable performance  
- Revenue shows consistent growth over time  

---

## 💡 Conclusion
This project demonstrates how SQL can be used to transform raw data into actionable insights. The findings can help businesses optimize marketing strategies, inventory management, and operational efficiency.
